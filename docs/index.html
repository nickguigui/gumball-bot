Perguntas frequentes

É grátis mesmo?

Sim. Você só digita seu número e o código no WhatsApp: não precisa instalar nada nem criar conta. Se quiser ajudar a manter o servidor, use o botão Apoiar, com o valor que quiser.

Preciso deixar o computador ou o celular ligado?

Não. Depois de conectar, ele roda na nuvem. Só abra o WhatsApp desse número pelo menos a cada 14 dias, senão o WhatsApp desconecta os aparelhos vinculados.

Outras pessoas conseguem usar o bot no meu número?

Não. Só você: o bot obedece apenas às mensagens do seu número, em grupos e no privado. Comando de qualquer outra pessoa é ignorado.

Tem risco de ban?

O WhatsApp não tem API oficial para bots de grupo, então ele funciona como um WhatsApp Web. O bot espaça os envios para parecer humano, mas o risco existe. Para risco zero, use um chip secundário.
